# Contributing

Changes should improve the clarity, verifiability, or operational safety of the mesh contract.

1. Identify the normative requirement or ambiguity addressed.
2. Update schemas, architecture text, and templates together.
3. Add positive and negative validation cases for contract changes.
4. Use synthetic examples only. Never commit credentials, private repository names, or personal data.
5. State compatibility impact and whether a major schema version is required.

Do not claim conformance based on JSON parsing alone. Changes must be checked against schema constraints and cross-file invariants.
